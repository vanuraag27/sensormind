# SensorMind

Your phone knows more than you think.

A browser-based sensor intelligence application that detects activity, counts steps, and creates automations - all on your device.

## 📖 Documentation

**Before using, read the [Standard Operating Procedure (SOP)](SOP.md)**

## 🚀 Quick Start

1. Open the app
2. Click "Enable Sensors"
3. Allow permissions
4. Start moving!

## ✨ Features

- 🚶 Activity Detection (Walking, Running, Driving, etc.)
- 👣 Step Counting with Goals
- ⚡ Automation Engine
- 🔊 Sound Effects (Walking, Running, Fall)
- 🖐️ Gesture Recording
- 🔒 Privacy Controls (Do Not Record)
- 📊 Activity Timeline & Insights
- 🏠 Places (Home, Work)

## 🔧 Requirements

- Modern browser (Chrome, Safari, Firefox)
- Smartphone recommended (for sensors)
- Motion permissions
